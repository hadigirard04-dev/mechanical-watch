# 开发日志 · mechanical-watch

## 2026-10-17/18 · 从零构建

**目标**：电影级机械腕表展示页，实时 3D，六幕滚动叙事，禁止用视频/整图缩放冒充拆解。

**交付**：`E:\codexxx\mechanical-watch\`（见 README.md 的文件结构与验收清单）。

### 关键决定

- **不用外部模型**：全部几何程序化生成。理由是"零件必须能被独立控制"，外部 GLB 通常是一整块网格，
  要么拆件成本高，要么动画只能是整体变换。
- **齿形用真渐开线**：`ψ(r) = ψ_p + inv(α_p) − inv(α_r)`，齿中线固定在局部角 0°，
  于是啮合相位可以解析给出：`rot_A = ∠AB`，`rot_B = ∠BA − π/z_B`。这样齿是真的咬合，不是视觉贴图。
- **传动数值全部由齿数推导**，不硬编码：发条盒 88 齿 → 11 叶 → 二番车 1 转/小时 → … → 擒纵轮 720 转/小时
  → `720×20×2 = 28 800 次/小时`，与 4 Hz 摆轮自洽；动力储存 42 h = 发条盒 5.25 转 ÷ (1/8 转/小时)。
- **机芯 Z 层高按真表比例压缩**：主夹板 0.8 → 条盒鼓 0.85~2.45 → 四层轮系 1.40/2.65/2.95/3.25/3.55 →
  桥板 3.70~4.40 → 摆轮 4.80 → 摆夹板 5.30~5.95（总高 5.95 mm）。二番车必须高于条盒鼓顶面，
  擒纵层必须独立于四番车层，否则同层平面冲突——这两条是脚本查出来的，不是猜的。
- **机芯整体绕 Y 翻转 180°**：桥板与摆轮朝向底盖，与真表一致；因此第 3 幕的镜头绕到表背看机芯。
- **两档时间基准**：默认 ×60 展示倍速，可切真值 ×1；擒纵与摆轮另有限频，读数表把"实际/显示"分列。
  这是为了让"齿轮在转"可见，同时不谎报转速。

### 踩过的坑（都已修）

| 现象 | 根因 | 修法 |
| --- | --- | --- |
| 表壳像横躺的管子、盘面在管子顶上 | `LatheGeometry` 默认绕 **Y** 轴旋转，而剖面是按 Z 轴写的 | `lathe()` 里统一 `rotateX(π/2)`；所有圆柱同理（`cylZ`） |
| 指针完全不可见（连轮廓都没有） | `wrapIn` 把指针当时为 0 的"浮现生长"缩放复制到了爆炸父节点 | 父节点只继承位置与旋转，缩放留给内层对象 |
| 金属全白、过曝 | 直射光叠加 + 环境贴图偏暗，于是把灯调得很亮 | 自建影棚 HDR 环境（正面柔光箱 1.95 + 侧光 + 顶光 + 背光），曝光 0.8，泛光阈值 0.94 |
| 盘面/指针像黑镜 | 平抛光面只反射环境，而环境贴图正面是暗的 | 同上，正面加柔光箱；盘面 metalness 0.6 + clearcoat 0.9 |
| 分解视图读不出层次 | 分离轴几乎与视线重合 | 腕表在第 2–3 幕前倾 0.5–0.62 rad |
| 竖屏特写被裁 | 竖屏水平视角窄 | 相机按 `1.6/aspect` 沿视线退后（上限 2.2） |
| `movement.js` 中文注释乱码 | 用 PowerShell `Get-Content -Raw`（PS 5.1 按 ANSI 解码）读改写 UTF-8 文件 | 重写文件；此后含中文的文件只用 edit/write 工具改 |

### 验证

- `node scripts/check-train.mjs`：8/8 通过（啮合中心距误差 8.88e-16 mm；二番车 1 转/小时；
  四番车 1 转/分钟；擒纵 28 800 次/小时；动力储存 42 h；旋向逐级交替；135 对零件平面/Z 冲突检查；
  全部零件在机芯半径 14.3 mm 内）。报告：`docs/train-check.txt`。
- `python -B -X utf8 scripts/capture.py --mobile --probe`：14 张截图（桌面 6 + 竖屏 6 + 真实节拍 2）+ 交互探测，
  0 个控制台错误；帧率 165 fps、draw call 253、三角面 210 k、纹理 31、几何体 99。
- 交互探测：点击「探索机芯」后幕位置由 3.75 前进到 3.00（第 4 幕起点）；
  「切换真实节拍 ×1」按钮文案与 `aria-pressed` 正确翻转，读数表随之更新。
- **传动功能性验证**（两个时刻读取各轮角度差）：旋向交替 = True；相邻角速度比 0.125 / 0.125 / 0.133
  与齿数比 11/88、8/64、8/60 完全一致；0.5 秒内四番车 −3.23 rad（1 转/秒 = ×60 展示倍速）、
  擒纵轮 +6.49 rad（2 转/秒，限频显示）、摆轮 −7.95 rad（1.1 Hz 显示节拍）。
  这一步查出并修掉了"所有齿轮同向旋转"的符号重复 bug。
- 逐张查看截图后修复了 7 项（见 DESIGN.md 的视觉审查记录）。
